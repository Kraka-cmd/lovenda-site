    Oplevering

    Een pull request of rapport met wat is gewijzigd, hoe het is getest en wat niet is gecontroleerd.

Vragen

Wat teams vooraf willen weten

Waar komt de code te staan?

In je eigen repository, via een pull request. Je team kan alles reviewen voordat het wordt samengevoegd.

Werk je met productiegegevens?

Nee. Ik werk in een lokale, test- of acceptatieomgeving met testaccounts.

Wat doet Claude en wat doe jij?

Claude Code schrijft en test mee. Ik bepaal de aanpak, lees elke wijziging zelf na en ben verantwoordelijk voor wat ik oplever.

Wat als ik tijdens het werk iets extra wil?

Dat kan. Wensen buiten de afgesproken criteria doe ik op uurbasis, nadat je akkoord hebt gegeven.

Welke feature is geschikt als eerste?

Een feature van één tot vijf werkdagen, waarvan het gewenste gedrag in een paar zinnen te beschrijven is.

Ligt er een feature die blijft liggen?

Mail kort om welke applicatie het gaat en wat er moet komen. Dan plan ik een kennismaking in en maak ik een vaste prijs.
